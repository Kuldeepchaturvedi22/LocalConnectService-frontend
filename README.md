# LocalConnectService React Frontend

## Run

1. Install Node.js and npm.
2. Copy `.env.example` to `.env`.
3. Run `npm install`.
4. Run `npm run dev`.

The app expects the Java API at `http://localhost:8080/api/v1`.

This foundation includes unified login, protected session state, responsive navigation and a role-aware dashboard shell. Existing prototype workflows in `../outputs` will be migrated module-by-module instead of being duplicated.
